WHAT WAS ADDED

- Website credit across the site: MHMD OBEIDAT.

MAP NOTE
The interactive map is designed as a service-coverage overview for presentation and navigation.
It is not intended to represent legal or surveyed administrative boundaries.
The map uses Leaflet and OpenStreetMap and therefore needs internet access for map tiles.

HOW TO RUN
1. Double-click START-AVTR.bat
2. Open http://localhost:8000

PHONE / EXTERNAL DEMO
Keep the local server running, then in a second PowerShell window run:
cloudflared tunnel --url http://localhost:8000
Open the generated https://*.trycloudflare.com link on the phone.
